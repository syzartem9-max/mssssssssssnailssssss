## Как запустить (пошагово)

### 1. Подготовка
Тебе нужен аккаунт на [Railway.app](https://railway.app) (бесплатно) или любом хостинге с Node.js.

### 2. Загрузка проекта
1. Скачай эту папку `ms-nails-bot`
2. Зайди на Railway → New Project → Deploy from local or GitHub
3. Или используй Render / Fly.io / VPS

### 3. Переменные окружения
В настройках проекта добавь:

```
BOT_TOKEN=9091994479:AAHjm5Wj-iyWYLHRtA6QyuO6Dkyut-xkCbE
ADMIN_LOGIN=admin
ADMIN_PASSWORD=Artemkin3003!
PORT=3000
WEBAPP_URL=https://твой-домен.railway.app
PAYMENT_PHONE=+79226466607
PAYMENT_NAME=Варвара Сергеевна С
PAYMENT_BANK=Сбербанк
PREPAYMENT_AMOUNT=300
```

`WEBAPP_URL` — это адрес, который выдаст Railway после деплоя (например `https://ms-nails-bot-production.up.railway.app`)

### 4. Настройка бота в BotFather
1. Открой @BotFather
2. `/mybots` → выбери своего бота → **Bot Settings** → **Menu Button**
3. Или `/setmenubutton` → укажи URL твоего Mini App
4. Также можно использовать команду `/start` — бот сам покажет кнопку

### 5. Локальный запуск (для теста)
```bash
cd ms-nails-bot
cp .env.example .env
# отредактируй .env
npm install
npm start
```

Открой `http://localhost:3000` в браузере (в Telegram WebApp будет работать лучше).

## Важно
- Токен бота сейчас в коде для удобства. После деплоя лучше хранить только в переменных окружения.
- База данных SQLite — для простоты. При большом количестве записей можно перейти на PostgreSQL.
- Админ подтверждает оплату вручную после нажатия клиентом «Я оплатил».

Если что-то не заработает — напиши, разберёмся.
